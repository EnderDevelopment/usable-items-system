# Usable Items System

Make items usable in your ESX Legacy server with ease.

## Features

- Progress bar for using items
- Healing functionality for items

## Requirements

- ESX Legacy
- MySQL-Async

## Installation

1. Download the script
2. Place it in your resources folder
3. Add `start usable_items` to your server.cfg

## Usage

- Add items to the `Config.UsableItems` table in `config.lua`
- Use the items in-game

## Configuration

- `Config.UsableItems`: Configure the items that can be used
- `Config.Database`: Configure the database settings
